## GiaMol-WQED

This is a repository with codes and data of research on Giant Molecules in Waveguide QED. If you use any document in this repository in your research, please cite the respective papers.

### Code Water-Molecule.ipynb:
In this code we present the data and analysis of decoherence free qubit and directional photon emission.
Y Wang, JJ García-Ripoll, AC Santos, arXiv preprint arXiv:2603.27443.
