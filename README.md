## GiaMol-WQED

This repository contains the **code and data** associated with our research on **Giant Molecules in Waveguide Quantum Electrodynamics (Waveguide QED)**.

If you use any of the code, data, or other materials provided in this repository in your research, please cite the corresponding publication(s).

### `Water-Molecule.ipynb`

This Jupyter notebook contains the code, data, and analysis used to study:

- **Decoherence-free qubits**
- **Directional photon emission**
